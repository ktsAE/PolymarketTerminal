### Checked and clean

- **SQL injection: none.** Every statement in `store.ts` uses `?` placeholders; the only built fragment is a constant `where` list at `store.ts:359-361`.
- **Command injection: none.** `execFile('notify-send', [...])` with an arg array in 2 places (`walletwatch.ts:112`, `cli.ts:219`); no `exec`, `spawn`, `shell:true`, `xdg-open` anywhere in `radar/`. The `o` key only prints a URL.
- **Path traversal: none reachable from remote data.** All paths come from env vars or constants; the only user path is `case-add <file>` (`cli.ts` readFileSync of an argv path, intended). No API value is used in a file name.
- **SSRF: none.** All base URLs are constants (`polymarket.ts:8-13`, `livebook.ts:161`); user input only goes through `encodeURIComponent` into query strings. The Polygon RPC URL is user-configured via `RADAR_POLYGON_RPC` and never echoed (`chainfunding.ts:34` prints status only; `polymarket.ts:248-252,305` strips query strings from error URLs).
- **Secrets in logs:** `.radar/daemon.log` has 0 matches for key/token/bearer/authorization. Stack trace at `app.ts:458-462` prints local paths only.
- **Already landed in the working tree while I read (by other nodes, not re-verified for tests):** request timeout + `Retry-After` + no-retry on 400/401/403/404/410 (`polymarket.ts:278-305,607-619`), atomic writes for `wallets.json`/`people.json`, per-feed try/catch in `pollFeeds`. VERDICT fix 3 (`app.ts` catches) was **not** present yet.
- **Listener/timer hygiene:** `LiveBookFeed.stop()` clears all four timers and nulls socket handlers; TUI `quit()` clears timers and the book feed; raw mode is restored on `exit`.

## Top-10 fix list

1. **Sanitise at ingress and in `fit()` (#1, #16).** Add `safeText(s)` that removes `[\x00-\x08\x0b-\x1f\x7f-\x9f]`, U+200B-200F, U+202A-202E, U+2066-2069, U+FEFF; call it in `mapEvent`, `mapPrint`, `mapTrade` names, `searchProfiles`, `publicProfile`, `recentTrades`/`userPositions` titles, news `clean()`, jina `cleanPostText`, and on every `error.message` shown in red. Also make `fit()`/`truncate()` strip them (they are documented "plain text only"). Add a unit test with ESC/OSC/CSI/C1/RLO samples that asserts `/\x1b|\x9b/` never appears in `render()` output except from `c.*`.
2. **Fix `decodeEntities` (#2).** Reject code points outside 0x20-0x10FFFF (and surrogates) with a `try`, then run `safeText` after decoding. Test `&#27;`, `&#x110000;`, `&#99999999;`.
3. **Make the rate limiter concurrency-safe (#3).** Serialise slot reservation: `const slot = Math.max(this.now(), this.next); this.next = slot + minIntervalMs; await sleep(slot - now)` before the fetch. Add a shared "cool-down until" set on any 429 (honours Retry-After for all workers) and cap total retries per second. Test with 10 parallel calls: timestamps must be >= minInterval apart.
4. **Reword and always show the caveat (#4).** In Holders/Newbies/Xray/Cluster: show short address, not display name, next to `NEW ACCOUNT`, `!` and `≈` (name only on the explicit wallet card, uncoloured); remove red/yellow on person matches and say "same name as X; many people share names; not an identification" on the same line; show the one-line "new accounts are mostly ordinary people; not evidence of wrongdoing" at any height. Change `README.md:47` framing; remove or source-cite the `ALLEGED_CONCRETE` named X user in `cases.seed.ts:89`.
5. **Crash resilience (#5).** `.catch` on the eight `void`/`.then` chains, `schedule()` re-arms in `finally`, add `process.on('unhandledRejection', ...)` that shows a status-line error instead of exiting. Test: make `poll` reject once and assert polling resumes.
6. **Notification hardening (#6, #15).** `notify()`: strip control chars, escape `& < >`, pass `--` before the positionals, add `timeout` to `execFile`, cap to 5 per pass in the CLI too.
7. **Don't overwrite a corrupt follow list (#7).** On parse error rename the file to `wallets.json.corrupt-<ts>` (or throw like `people.ts`) before any write; surface the error in the Following tab.
8. **Safer wallet resolution (#8).** Anchor address parsing (whole input, or inside a `polymarket.com/profile/` URL); when more than one profile matches a handle exactly, refuse and list the addresses. Show the resolved address and creation date before saving.
9. **WebSocket and fetch hygiene (#9, #10).** Reset `attempt` only after a valid frame plus 30 s uptime; add jitter and a cap of N fast failures before staying on REST polling. Give `httpFetchText` an `AbortSignal.timeout(15_000)` and a body size cap (e.g. 2 MB via `content-length` check + `res.text()` slice).
10. **Bound storage and pin the runtime (#11, #12, #14).** Prune `wallet_identity`/`holder_profiles`/`news_items` (e.g. 90 days), `wal_checkpoint(TRUNCATE)` + occasional `VACUUM`, rotate `daemon.log` and the jsonl logs; create `.radar/` with mode 0700 and files 0600; add `"engines": {"node": ">=22.13"}` and a doctor check for `node:sqlite`.
